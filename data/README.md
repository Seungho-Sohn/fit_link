# 헬스장 · 기구 데이터

시그니처 기능(기구 사진 → 같은 기구가 있는 헬스장)이 쓰는 데이터입니다.
이 폴더의 CSV 파일 3개가 원본이고, 앱은 여기서 만든 `lib/data/gym_data.dart`를 씁니다.
지금 들어 있는 내용은 목업이에요. 제휴 헬스장 데이터가 오면 이 파일들만 바꾸면 됩니다.

| 파일 | 한 줄에 들어가는 것 |
|---|---|
| `gear_catalog.csv` | 기구 모델 하나 |
| `gyms.csv` | 헬스장 하나 |
| `gym_gear.csv` | "이 헬스장에 이 기구가 있다" 한 건 |

## 바꾸는 순서

1. 엑셀(또는 구글 시트)로 CSV를 열어 고칩니다. 첫 줄(머리글)의 열 이름은 바꾸지 마세요. 열 순서는 바꿔도 됩니다.
2. 저장할 때 **"CSV UTF-8(쉼표로 분리)"** 형식을 고릅니다. 그냥 "CSV"로 저장하면 한글이 깨집니다.
3. 프로젝트 폴더에서 아래 명령을 실행합니다.
   ```
   dart run tool/data/import_gym_data.dart
   ```
   - 문제가 없으면 `lib/data/gym_data.dart 를 새로 만들었어요 — 기구 N종 · 헬스장 N곳 …`이 나옵니다.
   - 문제가 있으면 `gyms.csv 7행: 위도 "abc"이(가) 올바르지 않아요`처럼 파일과 **엑셀 행 번호**를 알려 주고, 앱 코드는 바꾸지 않습니다.
4. 바뀐 CSV와 `lib/data/gym_data.dart`를 함께 커밋합니다. 3번을 잊으면 테스트(`test/gym_data_test.dart`)가 실패해서 알려 줍니다.

## 열 설명

### gear_catalog.csv

| 열 | 예 | 규칙 |
|---|---|---|
| 기구ID | `hs-pl-pulldown` | 영문 소문자·숫자·하이픈(-)만, 겹치면 안 됨. 한번 정하면 바꾸지 마세요(회원 제보·운영자 등록이 이 ID로 저장됩니다) |
| 브랜드 | `Hammer Strength` | |
| 제품라인 | `Plate-Loaded` | |
| 이름(한글) | `프론트 풀다운` | 화면에 보이는 이름 |
| 이름(영문) | `Front Pulldown` | |
| 종류 | `랫풀다운` | `랫풀다운` / `로우` / `체스트 프레스` / `레그 프레스` 중 하나. 종류마다 기구가 1개 이상 있어야 함 |
| 구동방식 | `플레이트 로디드` | `플레이트 로디드` / `셀렉토라이즈드` 중 하나 |
| 타겟부위 | `광배근` | |

새 종류(예: 스쿼트 머신)를 쓰려면 앱 코드의 `GearCategory`에 먼저 추가해야 합니다.

### gyms.csv

| 열 | 예 | 규칙 |
|---|---|---|
| 헬스장 | `스틸핏 강남점` | 겹치면 안 됨. `gym_gear.csv`와 글자까지 똑같아야 함 |
| 위도 · 경도 | `37.4997` · `127.0300` | 한국 범위(위도 33~39, 경도 124~132). 네이버·카카오 지도에서 장소를 우클릭하면 좌표를 볼 수 있어요 |
| 면적(평) | `150` | 1 이상의 정수 |
| 평점 | `4.8` | 0~5 |
| 운영시간 | `06:00–24:00` | 보이는 그대로 |
| 대표편의 | `PT 가능` | 목록 태그로 보임 |
| 현재인원(데모) | `37` | 홈 화면 혼잡도 데모용 숫자. 실제 혼잡도 연동 전까지 아무 값이나 |

### gym_gear.csv

| 열 | 예 |
|---|---|
| 헬스장 | `스틸핏 강남점` (`gyms.csv`에 있는 이름) |
| 기구ID | `hs-pl-pulldown` (`gear_catalog.csv`에 있는 ID) |

헬스장마다 보유 기구가 1개 이상 있어야 합니다. 같은 줄이 두 번 나오면 오류입니다.

## 참고

- 회원의 "있어요/없어요" 제보와 운영자 등록은 이 데이터 위에 덧붙여집니다. 운영자가 등록한 헬스장은 이 파일의 보유 기구 대신 운영자 등록 내용이 쓰입니다.
- 헬스장 이름이나 기구ID를 바꾸거나 지우면, 그 이름·ID로 저장돼 있던 운영자 등록·회원 제보는 앱에서 버려집니다.
